##  Descripción

Carrito de compras funcional construido con **JavaScript Vanilla**, sin frameworks. 
Implementa manipulación del DOM, eventos, arrays y localStorage.

##  Características

-  Agregar/eliminar productos
-  Persistencia con localStorage
-  Cálculo automático de total
-  Diseño responsive

##  Tecnologías

- HTML5
- CSS3 (Skeleton Framework)
- JavaScript ES6+

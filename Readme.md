## 🚀 Características destacadas por proyecto

### 🛒 Carrito de Compras
- Agregar/eliminar productos del carrito
- Cálculo dinámico de totales
- Persistencia con LocalStorage
- Diseño responsive

### ₿ Buscador de Criptomonedas
- Consumo de API REST de criptomonedas
- Conversión en tiempo real
- Manejo de promesas con Async/Await
- Validación de formularios

### 📅 Administrador de Citas (TypeScript)
- Migración completa de JavaScript a TypeScript
- Tipado estricto de componentes y props
- Uso de interfaces y types
- Almacenamiento local de citas

### 🏥 APV - Veterinaria MERN (Full Stack)
- Autenticación completa (Registro, Login, JWT)
- Confirmación de cuenta por email (Nodemailer + Mailtrap)
- Recuperación de contraseña
- CRUD completo de pacientes
- Rutas protegidas (React Router v7)
- Context API para autenticación y pacientes
- Custom hooks (useAuth, usePacientes)
- Middleware de autenticación en backend
- Despliegue profesional (Netlify + Render)
